# SPIBB with Multiple Behavior Policies

Safe Policy Improvement with Baseline Bootstrapping (SPIBB)
learns a new policy from a fixed offline dataset. 

Standard SPIBB assumes one policy generated the dataset and that
this same policy is the baseline. It guarantees with high probability 
that the new policy is not much worse than a baseline policy.
Where the state-action counts are below a threshold N, SPIBB copies the baseline instead
of improving it.

However, datasets are often pooled from several arbitrary behavior policies. 
Different operators, older versions of a system, exploratory runs.

This project studies SPI in that setting.

## Research Question

When an offline dataset is generated by K arbitrary behavior policies, 
which baseline should SPIBB bootstrap on, and what safe-improvement  
guarantee does each choice give?
