## Offline / Batch Reinforcement Learning

Learning a policy from a fixed previously collected dataset,
without further interaction with the true environment.

## Baseline Policy

The existing policy relative to which safe improvement is evaluated.

## Baseline Bootstrapping

Constraining the learned policy to reproduce the baseline policy
in insufficiently supported parts of the state-action space.

## Aleatoric uncertainty

Randomness inherent in the environment even if the true transition
model were perfectly known.

## Epistemic uncertainty

Uncertainty about the true transition model.

## Ambiguity set

A set of transition probability distributions considered plausible.
